Pristupačnost · VOJS

Glas treba biti dostupan svima.

VOJS težimo učiniti preglednim i jednostavnim na različitim Android uređajima.

Navigacija

Web sadržaj koristi semantičke HTML elemente, poveznice i jasno istaknute naslove.

Veličine zaslona

Web je responzivan; Android Compose sučelje može se pomicati na manjim zaslonima.

Povratne informacije

Ako otkriješ problem sa čitačem zaslona, kontrastom ili fokusom, prijavi ga preko GitHub Issues.

Stanje provjere

Potpuna pristupačnost nije certificirana; stvarna testiranja i dalje su dio razvoja.
